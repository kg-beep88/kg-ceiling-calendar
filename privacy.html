Privacy Policy / 隐私政策

Simple summary / 简单说明: This app uses Google Calendar only after the user gives permission. Calendar data is sent directly between the user's browser and Google. / 此应用只在用户同意后使用谷歌日历。日历资料直接在用户浏览器和谷歌之间传送。

Data used / 使用的资料

The app reads and changes Google Calendar events so the user can plan ceiling work. / 应用读取和修改谷歌日历事项，让用户安排天花工作。

Data storage / 资料储存

The application is hosted as a static website. It has no separate KG server database. A temporary access token is kept only in browser memory. The last downloaded calendar view may be cached locally on the user's device for display. / 此应用是静态网站，没有独立的 KG 服务器数据库。临时访问令牌只保存在浏览器记忆中。最近下载的日历画面可能暂存在用户设备中供显示。

Data sharing / 资料分享

The app does not sell calendar data and does not send calendar data to advertisers. / 应用不会出售日历资料，也不会把日历资料发送给广告商。

Removing access / 取消权限

The user can remove the app's access from their Google Account security settings at any time. / 用户可随时在谷歌账号安全设置中取消应用权限。

Contact / 联系

Contact the KG application administrator for questions about this internal work tool. / 如对此内部工作工具有疑问，请联系 KG 应用管理员。
